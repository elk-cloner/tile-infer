# Image

The development image for cuTile Python, cutile-rs, TileGym and mistral.rs on one CUDA version. The target GPU is an RTX PRO 6000 Blackwell (sm_120).

## Versions

These are target versions. They are not yet verified together.

| Component | Version |
| --- | --- |
| CUDA | 13.3 |
| Driver (on the host) | r580+ |
| cuTile Python | 1.7 |
| Rust | 1.89+ |
